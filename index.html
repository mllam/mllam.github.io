Machine learning for limited area weather modelling

mllam is an open community developing data-driven weather forecasting models for limited area modelling (LAM), together with the tools to prepare training data, build model graphs and evaluate the results. All development happens in the open on GitHub, and contributions are welcome.

mllam on GitHub Join us on Slack

Packages

neural-lam

Graph-based neural weather prediction models for limited area modelling, built on PyTorch and PyTorch Geometric. Includes LAM versions of the Keisler (2022) graph model, GraphCast and the hierarchical model from Oskarsson et al. (2023), for training and running forecasts.

Repository

mllam-data-prep

Prepares training datasets for data-driven weather models from a declarative YAML config: data sources, variables, transformations and how they map onto the model's inputs. Produces training-optimised zarr datasets.

Repository PyPI

weather-model-graphs

Creates, visualises and stores the graphs used by message-passing, graph-based weather models, such as the graphs neural-lam trains on.

Repository Documentation PyPI
